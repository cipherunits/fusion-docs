## چیست

**Fusion Desktop** اپ گرافیکی رسمی همراه Fusion Framework است (ساختهٔ [Cipher Unit](https://cipherunit.xyz)). برای توسعه‌دهندگانی که گردش‌کار بصری روی دسکتاپ را ترجیح می‌دهند، مکمل CLI باینری `fusion` است.

صفحهٔ اصلی دانلود: [Fusion Desktop](/fa/gui).

## پلتفرم‌ها

| پلتفرم | یادداشت |
| --- | --- |
| **Windows** | Windows 10 / 11 — نصب‌کنندهٔ کاربر، نصب‌کنندهٔ سیستم، `.zip`، بیلدهای CLI — **x64** و **Arm64** |
| **Linux** | `.deb` (Debian/Ubuntu)، `.rpm` (RHEL/Fedora/SUSE)، Snap، `.tar.gz`، CLI — **x64** و **Arm64** |

برای ماتریس دقیق artifactها به UI زندهٔ دانلود نگاه کنید: [/fa/gui](/fa/gui).

## ارتباط با CLI

| کار | CLI | Desktop |
| --- | --- | --- |
| اسکفولد پروژه | `fusion init` | UI راهنما (همان چیدمان پروژه) |
| اجرای دستورات env | `fusion command` | اکشن‌های UI روی همان `commands` داخل `fusion.<env>.json` |
| نصب ماژول | `fusion add` | گردش‌کار ماژول هرجا در اپ در دسترس باشد |
| به‌روزرسانی خود CLI | `fusion update` | به‌روزرسانی اپ از طریق نصب‌کننده‌های خودش |

فرمت روی دیسک پروژه یکسان می‌ماند (`fusion-framework.toml`، `fusion.<env>.json`، ماژول‌های route). می‌توانید روی یک پروژه CLI و Desktop را با هم مخلوط کنید.
