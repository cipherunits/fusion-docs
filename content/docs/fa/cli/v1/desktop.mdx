## چیست؟

**Fusion Desktop** رابط گرافیکی رسمی همراه Fusion Framework است (ساختهٔ [Cipher Unit](https://cipherunit.xyz)). مکمل باینری `fusion` برای کسانی است که گردش‌کار ویژوال می‌خواهند.

صفحهٔ دانلود: [Fusion Desktop](/fa/gui).

## پلتفرم‌ها

| پلتفرم | توضیح |
| --- | --- |
| **Windows** | ویندوز ۱۰ / ۱۱ — نصب کاربر، نصب سیستم، `.zip`، CLI — **x64** و **Arm64** |
| **Linux** | `.deb`، `.rpm`، Snap، `.tar.gz`، CLI — **x64** و **Arm64** |

ماتریس دقیق artifactها: [/fa/gui](/fa/gui).

## رابطه با CLI

فرمت روی دیسک پروژه یکی است (`fusion-framework.toml`، `fusion.<env>.json`، ماژول‌های route). می‌توانید CLI و Desktop را روی یک پروژه با هم استفاده کنید.
