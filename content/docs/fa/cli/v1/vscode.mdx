## چیست؟

**Fusion Snippets** اکستنشن ادیتور Cipher Unit است که snippet برای **Fusion Framework** در **Python**، **TypeScript / Node.js** و **C#** می‌دهد.

الگوهای رایج را سریع می‌کند: ماژول‌های route، `@route` / `route()` / `[Route]`، مسیرهای HTTP سفارشی، middleware، پاسخ با `status` / `header`، و pagination.

## نصب

1. **VS Code** یا **Cursor** را باز کنید
2. Extensions (`Ctrl+Shift+X` / `Cmd+Shift+X`)
3. جستجو: **Fusion Snippets** (ناشر: Cipher Unit / cipherunits)
4. نصب کنید؛ در فایل `.py` / `.ts` / `.cs` با پیشوند IntelliSense صدا بزنید

> ابزارهای VFX به نام «Fusion» (DaVinci) را با این اکستنشن اشتباه نگیرید — مخصوص **Fusion Framework** است.
