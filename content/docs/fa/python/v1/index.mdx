## نمای کلی

پکیج Python binding اصلی زبان برای **Fusion Framework** است.

ماژول‌های HTTP کلاس‌محور را با `@route` و `FusionBaseApi` تعریف می‌کنید. مسیریابی، binding پارامتر، پارس، و سریالایز پاسخ در هستهٔ مشترک Rust (`fusion-core`) اجرا می‌شود. Python لایهٔ نازک تجربهٔ توسعه‌دهنده می‌ماند.

نصب:

```bash
pip install fusion-framework
```

در حال مشاهدهٔ **v1** هستید. نسخه‌های جدید وقتی منتشر شوند در انتخابگر نسخه ظاهر می‌شوند.

## چه چیزی می‌گیرید

- APIهای کلاس‌محور: `get` / `post` / `put` / `patch` / `delete`
- پارامترهای typed هندلر از path، JSON body، یا query
- UI خودکار Swagger / OpenAPI (`fusion.<env>.json` + متادیتای `@route` هر route)
- Middleware سراسری و سطح route (به‌صورت پیش‌فرض هیچ‌کدام — خودتان ثبت می‌کنید)
- هلپرهای `status` مثل `status.HTTP_SUCCESS` (200)
- هندلر و middleware هم sync و هم **async**
- `HTTPException` برای پاسخ‌های خطای ساخت‌یافته
