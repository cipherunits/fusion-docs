## نمای کلی

بستهٔ پایتون binding اصلی **Fusion Framework** است.

ماژول‌های HTTP کلاس‌محور را با `@route` و `FusionBaseApi` تعریف می‌کنید. مسیریابی، بایندینگ پارامتر، پارس و سریالایز پاسخ در هستهٔ مشترک Rust (`fusion-core`) اجرا می‌شود.

```bash
pip install fusion-framework
```

شما در حال مشاهده **v1** هستید.
