## نمای کلی

Fusion از ماژول‌های route ثبت‌شده **Swagger UI** و JSON OpenAPI را mount می‌کند.

| تنظیم | پیش‌فرض |
| --- | --- |
| `swagger.enabled` | `true` |
| `swagger.path` | `/swagger` |

پیکربندی زیر `config.swagger` در `fusion.<env>.json`. Scaffoldهای CLI معمولاً در **dev** روشن و در **stage** / **prod** خاموش‌اند. schema کامل فایل: [تنظیمات و پیکربندی](../../architecture/v1/settings).

جزئیات بلوک JSON: [دستورات و محیط‌ها](../../cli/v1/command).
