## نمای کلی

باندینگ C# هستهٔ Rust را از طریق **`fusion-ffi`** (C ABI) صدا می‌زند. DX شبیه پایتون/Node است: `FusionApp`، `[Route]`، middleware، `Status` و settings.

نسخهٔ v1 روی یک **API HTTP قابل اجرا** تمرکز دارد. برابری کامل OpenAPI/Swagger با پایتون هنوز نیست.

پکیج مدیریت‌شده: NuGet [`Fusion-Framework`](https://www.nuget.org/packages/Fusion-Framework) (namespace سی‌شارپ: `FusionFramework`). کتابخانهٔ native از `fusion-ffi` می‌آید (در بیلدهای منتشرشده همراه پکیج NuGet).
