## نمای کلی

تنظیمات از طریق FFI از همان فایل‌های `fusion.<env>.json` بارگذاری می‌شوند (`FUSION_ENV`، پیش‌فرض `dev`). تایپ‌ها در namespace **`FusionFramework`** هستند (پکیج NuGet: **`Fusion-Framework`**).

کشف فایل، placeholderها، کلیدهای مصرف‌شده و schema کامل تولیدشدهٔ CLI:

→ **[تنظیمات و پیکربندی](../../architecture/v1/settings)**

```csharp
SettingsStore.Current.EnsureLoaded(Directory.GetCurrentDirectory());
var host = SettingsStore.Current.Host;
var port = SettingsStore.Current.Port;
var secret = SettingsStore.Current.Get("secret_key");
```

## استارت

```csharp
SettingsStore.Current.EnsureLoaded(Directory.GetCurrentDirectory());
using var app = new FusionApp(SettingsStore.GetSettings());
app.Listen(); // host/port از settings
```

اپ‌های scaffold یک helper استاتیک `CoreSettings` هم دارند که از `SettingsStore` می‌خواند — جایگزین JSON نیست.

## API

| API | نقش |
| --- | --- |
| `EnsureLoaded(extraRoots…)` | کشف JSON |
| `LoadJson(path, env, roots…)` | لود صریح |
| `Get(key, default?)` | مقدار / JSON node |
| `Merge(object)` | overlay |
| `Host` / `Port` / `Debug` / `Env` | فیلدهای رایج |
| `SettingsStore.Configure(values)` | merge روی singleton |

## تعویض محیط

```bash
FUSION_ENV=prod dotnet run
fusion command run:prod
```

`commands` فقط برای Fusion Tool است.
