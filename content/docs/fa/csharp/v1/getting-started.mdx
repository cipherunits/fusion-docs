## پیش‌نیازها

```bash
# from fusion-framework repo
cargo build -p fusion-ffi
dotnet build bindings/csharp/FusionFramework
```

اختیاری: `export FUSION_FFI_PATH=$PWD/target/debug/libfusion_ffi.so` (`.dll` / `.dylib` در Windows/macOS).

## Scaffold

```bash
fusion init --lang csharp --name my-app
# aliases: asp-core, aspnetcore
```

## اولین API

```csharp
using FusionFramework;

[Route("api/[module]")]
public class ProductModule : FusionBaseApi
{
    public object Get() =>
        Response(new { products_id = 12 }, Status.HTTP_SUCCESS);
}

public static class Program
{
    static readonly List<FusionMiddleware> Middleware = new();

    public static void Main()
    {
        Route.RegisterAll(typeof(Program).Assembly);
        SettingsStore.Current.EnsureLoaded(Directory.GetCurrentDirectory());
        using var app = new FusionApp(SettingsStore.GetSettings());
        foreach (var mw in Middleware) app.Use(mw);
        app.Listen();
    }
}
```

نمونه در مونوریپو: `examples/csharp_hello`.
