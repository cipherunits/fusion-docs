---
title: Fusion چیست و چه نیست
description: مرز دامنه — قابلیت‌هایی که Fusion امروز ارائه نمی‌دهد
---

Fusion یک فریم‌ورک اپلیکیشن HTTP با هستهٔ مشترک Rust است. برای جلوگیری از انتظار اشتباه، این قابلیت‌ها **امروز** در پکیج‌های فریم‌ورک نیستند:

| نیست | توضیح |
| --- | --- |
| **لایهٔ ORM / دیتابیس** | از هر کتابخانهٔ DB زبان خودتان استفاده کنید؛ Fusion یکی نمی‌فرستد |
| **DI container** | پایتون فقط **بایندینگ پارامتر** درخواست دارد؛ نه IoC |
| **صف‌های job پس‌زمینه** | worker/queue داخلی ندارد |
| **Runtime مارکت‌پلیس پلاگین** | پکیج‌های کتابخانه‌ای import عادی از طریق CLI هستند |
| **سوئیت OAuth / session auth** | فقط helperهای اختیاری Bearer JWT |
| **WebSockets / GraphQL / gRPC** | مدل request/response HTTP |
| **Templating / SSR** | API-محور |
| **سورس CLI داخل ریپو** | Scaffolding در **Fusion Tool** خارجی است |

اگر مستندات جای دیگر ویژگی‌ای را ذکر کرد که در راهنماهای زبان یا این بخش معماری نیست، قبل از تکیه، در سورس [fusion-framework](https://github.com/cipherunits/fusion-framework) تأیید کنید.
