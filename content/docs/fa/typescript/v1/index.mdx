## نمای کلی

باندینگ Node.js همان هستهٔ Rust پایتون را دارد. DX شبیه پایتون است: `FusionApp`، `route` / `router`، middleware، `status` و `settings`.

هندلرها از `this.params` / `this.query` / `this.body` / `this.state` استفاده می‌کنند — **بدون** تزریق پارامتر به امضای تابع مثل پایتون.

پکیج: `fusion-framework` (npm) از `crates/fusion-node`.
