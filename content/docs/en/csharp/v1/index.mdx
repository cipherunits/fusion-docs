## Overview

**ASP.NET Core (C#)** support for **Fusion Framework** is **coming soon**.

Fusion Tool already lists `asp-core` as a language option for scaffolding, but the .NET binding and package are not released yet.

You are viewing **v1**. This section will expand when C# support ships.

## What to use today

- Build APIs with the [Python package](../../python/v1)
- Optionally scaffold an ASP.NET-shaped layout with [Fusion Tool](../../cli/v1/getting-started):

```bash
fusion init --lang asp-core --name my-app
```

Prefer Python for production backends until the C# package is available.
