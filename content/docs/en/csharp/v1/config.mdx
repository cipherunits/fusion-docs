## Overview

Settings load through FFI from the same `fusion.<env>.json` files as other languages (`FUSION_ENV`, default `dev`). Types live in the **`FusionFramework`** namespace (NuGet package **`Fusion-Framework`**).

Shared discovery, placeholders, consumed keys, and full CLI-generated schemas:

→ **[Settings and configuration](../../architecture/v1/settings)**

```csharp
SettingsStore.Current.EnsureLoaded(Directory.GetCurrentDirectory());
var host = SettingsStore.Current.Host;
var port = SettingsStore.Current.Port;
var secret = SettingsStore.Current.Get("secret_key");
```

## Startup

```csharp
SettingsStore.Current.EnsureLoaded(Directory.GetCurrentDirectory());
using var app = new FusionApp(SettingsStore.GetSettings());
app.Listen(); // host/port from settings
```

Scaffolded apps also get a static `CoreSettings` helper that reads from `SettingsStore` — it does not replace JSON.

## API

| API | Role |
| --- | --- |
| `EnsureLoaded(extraRoots…)` | Discover JSON |
| `LoadJson(path, env, roots…)` | Explicit load |
| `Get(key, default?)` | JSON node / value |
| `Merge(object)` | Overlay |
| `Host` / `Port` / `Debug` / `Env` | Common fields |
| `SettingsStore.Configure(values)` | Merge into singleton |

## Switch environment

```bash
FUSION_ENV=prod dotnet run
fusion command run:prod
```

`commands` in JSON are for Fusion Tool only.
