## Status

**ASP.NET Core support is coming soon.** There is no NuGet package or recommended quickstart yet.

## Prepare a project scaffold

Fusion Tool can create an ASP.NET Core project shell:

```bash
fusion init --lang asp-core --name my-app --description "My Fusion app"
```

This sets up environment files and language-appropriate entrypoints. Runtime APIs will be documented here when the binding is released.

## Until then

Follow the [Python Getting Started](../../python/v1/getting-started) guide for a working Fusion API, and use [Fusion Tool](../../cli/v1) to manage environments and commands.
