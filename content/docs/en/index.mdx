## What is Fusion?

**Fusion Framework** is a cross-platform backend framework built on a shared Rust core and **FMA (Fusion Module Architecture)**.

You write class-based HTTP APIs in your preferred language. Routing, request parsing, parameter binding, and response serialization run in the Rust engine — language bindings stay thin and focused on developer experience.

## Language support

| Language | Status |
| --- | --- |
| **Python** | Available — `pip install fusion-framework` |
| **TypeScript / Node.js** | Available — `npm i fusion-framework` (see [Node guide](./typescript/v1)) |
| **C#** | Available — managed package + `fusion-ffi` (see [C# guide](./csharp/v1)) |

Start with [Python](./python/v1), [TypeScript](./typescript/v1), or [C#](./csharp/v1).

## Tooling

- **[Fusion Tool](./cli/v1)** — the official CLI for scaffolding projects, managing environments, and running project commands
- **[Fusion Desktop](https://fusion.cipherunit.xyz/en/gui)** — a graphical interface for managing Fusion backends on Windows and Linux

Fusion is open source under the [BSD License](https://github.com/cipherunits/fusion-framework/blob/main/LICENSE/).

## Versioning

Fusion is a young framework, so we use a deliberate versioning strategy while the core stabilizes.

The goal is continuous improvement toward a reliable foundation for production backends.
