## What is Fusion?

**Fusion Framework** is a cross-platform backend framework built on a shared Rust core and **FMA (Fusion Module Architecture)**.

You write class-based HTTP APIs in your preferred language. Routing, request parsing, response serialization, settings, and header helpers run in the Rust engine — language bindings stay thin and focused on developer experience.

Current framework package version in the open-source repository: **1.2.3**.

## Why Fusion exists

Teams often need the same HTTP semantics in more than one language. Fusion keeps **one core** for routing and serialization while exposing idiomatic APIs in Python, TypeScript/Node.js, and C#. Applications are composed from **route modules** and optional **reusable packages** instead of a single unstructured script.

## Language support

| Language | Status |
| --- | --- |
| **Python** | Available — `pip install fusion-framework` |
| **TypeScript / Node.js** | Available — `npm i fusion-framework` |
| **C#** | Available — NuGet `FusionFramework` + `fusion-ffi` |

## Versioning

Fusion is a young framework, so we use a deliberate versioning strategy while the core stabilizes.

The goal is continuous improvement toward a reliable foundation for production backends.
