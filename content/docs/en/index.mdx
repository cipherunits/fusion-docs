## Welcome

Fusion is a backend framework with a unified developer experience across multiple languages.

This documentation covers concepts, setup, and SDKs. Pick an SDK from the sidebar when you are ready to integrate.

## SDKs

Use the language that fits your stack. Each SDK section has its own versions and getting-started guides.

## Next steps

1. Choose an SDK in the sidebar.
2. Open **Getting Started** for install and a minimal example.
3. Explore the rest of that SDK’s docs for APIs and patterns.
