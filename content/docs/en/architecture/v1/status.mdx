## Overview

Fusion exposes HTTP status constants from **`fusion-core`** in every binding:

| Language | Import |
| --- | --- |
| Python | `from fusion_framework import status` then `status.HTTP_SUCCESS` |
| TypeScript / Node | `import { status } from "fusion-framework"` |
| C# | `using FusionFramework;` then `Status.HTTP_SUCCESS` |

`HTTP_SUCCESS` is an alias of `HTTP_200_OK` (`200`). Prefer these constants over raw integers.

```python
return self.response({"ok": True}, status=status.HTTP_SUCCESS)
```

```ts
return this.response({ ok: true }, status.HTTP_SUCCESS);
```

```csharp
return Response(new { ok = true }, Status.HTTP_SUCCESS);
```

Helpers (Rust / mirrored in bindings where exposed): `is_informational`, `is_success`, `is_redirect`, `is_client_error`, `is_server_error`.
