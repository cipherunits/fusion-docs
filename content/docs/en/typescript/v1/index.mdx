## Overview

TypeScript / Node.js bindings for **Fusion Framework** are **coming soon**.

The shared Rust core already powers a Node addon experimental path, but the published developer API and docs for production use are not ready yet.

You are viewing **v1**. This section will expand when the TypeScript package ships.

## What to use today

- Build APIs with the [Python package](../../python/v1)
- Scaffold a TypeScript-shaped project layout with [Fusion Tool](../../cli/v1/getting-started):

```bash
fusion init --lang typescript --name my-app
```

That creates the same project structure (`fusion.<env>.json`, `main.ts`, `core/settings.ts`, and so on). Prefer Python for runnable servers until the Node binding is officially released.
