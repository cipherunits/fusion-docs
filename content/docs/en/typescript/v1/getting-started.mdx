## Status

**TypeScript / Node.js support is coming soon.** There is no stable published package or recommended quickstart yet.

## Prepare a project scaffold

You can still create a TypeScript project shell with Fusion Tool:

```bash
fusion init --lang typescript --name my-app --description "My Fusion app"
```

This generates environment files and a `main.ts` / `core/settings.ts` layout. Runtime APIs for Node will be documented here when the binding is released.

## Until then

Follow the [Python Getting Started](../../python/v1/getting-started) guide for a working Fusion API, and use [Fusion Tool](../../cli/v1) to manage environments and commands.
