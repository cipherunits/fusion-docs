## Что такое Fusion?

**Fusion Framework** — кроссплатформенный бэкенд-фреймворк на общем Rust-ядре и **FMA (Fusion Module Architecture)**.

Вы пишете HTTP API на классах на удобном языке. Маршрутизация, разбор запросов, сериализация ответов, settings и хелперы заголовков работают в Rust-движке — языковые привязки остаются тонкими и сосредоточены на DX.

Текущая версия пакета фреймворка в открытом репозитории: **1.2.6**.

## Зачем нужен Fusion

Командам часто нужны одни и те же HTTP-семантики на нескольких языках. Fusion держит **одно ядро** для маршрутизации и сериализации и даёт идиоматические API на Python, TypeScript/Node.js и C#. Приложения собираются из **route-модулей** и опциональных **переиспользуемых пакетов**, а не из одного бесструктурного скрипта.

Fusion разрабатывает **[Cipher Unit](https://cipherunit.xyz)**.

## Поддержка языков

| Язык | Статус |
| --- | --- |
| **Python** | Доступен — `pip install fusion-framework` |
| **TypeScript / Node.js** | Доступен — `npm i fusion-framework` |
| **C#** | Доступен — NuGet `Fusion-Framework` (пространство имён `FusionFramework`) + `fusion-ffi` |

## Инструменты

- **[Fusion Tool](./cli/v1)** — официальный CLI для скаффолда проектов, управления окружениями и запуска команд проекта
- **[Fusion Desktop](/ru/gui)** — графический интерфейс для управления Fusion-бэкендами на Windows и Linux

Fusion — open source под [лицензией BSD](https://github.com/cipherunits/fusion-framework/blob/main/LICENSE/). Подробнее о команде: [cipherunit.xyz](https://cipherunit.xyz).

## Версионирование

Fusion — молодой фреймворк, поэтому пока ядро стабилизируется мы используем осознанную стратегию версий.

Цель — непрерывное улучшение к надёжной основе для продакшен-бэкендов.
