## Добро пожаловать

**Fusion Framework** — фреймворк для бэкенда с единым опытом разработки на нескольких языках.

Эта документация охватывает концепции, настройку и SDK. Когда будете готовы к интеграции, выберите SDK в боковой панели.

Fusion разрабатывается командой **[Cipher Unit](https://cipherunit.xyz)**.

## SDK

Выберите язык под ваш стек. У каждого раздела SDK свои версии и руководства по быстрому старту.

## Инструменты

- **[Fusion Tool](./cli/v1)** — официальный CLI для создания проектов и управления окружениями
- **[Fusion Desktop](/ru/gui)** — графический интерфейс для управления бэкендами Fusion на Windows и Linux

Подробнее о команде: [cipherunit.xyz](https://cipherunit.xyz)

## Дальнейшие шаги

1. Выберите SDK в боковой панели.
2. Откройте **Getting Started** для установки и минимального примера.
3. Изучите остальную документацию этого SDK: API и типовые сценарии.
