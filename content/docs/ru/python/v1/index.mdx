## Обзор

Python-пакет — основная языковая привязка для **Fusion Framework**.

Вы определяете HTTP-модули на классах с `@route` и `FusionBaseApi`. Маршрутизация, привязка параметров, разбор и сериализация ответов выполняются в общем Rust-ядре (`fusion-core`). Python остаётся тонким слоем DX.

Установка:

```bash
pip install fusion-framework
```

Вы смотрите **v1**. Новые версии появятся в селекторе версий после публикации.

## Что вы получаете

- API на классах: `get` / `post` / `put` / `patch` / `delete`
- Типизированные параметры хендлера из path, JSON body или query
- Автогенерация Swagger / OpenAPI UI (`fusion.<env>.json` + метаданные `@route` на маршруте)
- Глобальный и route-**middleware** (по умолчанию нет — регистрируете сами)
- Хелперы `status`, например `status.HTTP_SUCCESS` (200)
- Sync и **async** хендлеры и middleware
- `HTTPException` для структурированных ошибок
