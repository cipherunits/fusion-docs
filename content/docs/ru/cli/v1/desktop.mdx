## Что это

**Fusion Desktop** — официальный GUI-компаньон для Fusion Framework (разработан [Cipher Unit](https://cipherunit.xyz)). Дополняет CLI `fusion` для разработчиков, которым удобнее визуальный рабочий процесс на десктопе.

Основная страница загрузки: [Fusion Desktop](/ru/gui).

## Платформы

| Платформа | Примечания |
| --- | --- |
| **Windows** | Windows 10 / 11 — user installer, system installer, `.zip`, CLI-сборки — **x64** и **Arm64** |
| **Linux** | `.deb` (Debian/Ubuntu), `.rpm` (RHEL/Fedora/SUSE), Snap, `.tar.gz`, CLI — **x64** и **Arm64** |

Актуальную матрицу артефактов смотрите в UI загрузок: [/ru/gui](/ru/gui).

## Связь с CLI

| Задача | CLI | Desktop |
| --- | --- | --- |
| Scaffold проекта | `fusion init` | Guided UI (тот же layout проекта) |
| Запуск env-команд | `fusion command` | Действия UI над теми же `commands` в `fusion.<env>.json` |
| Установка модулей | `fusion add` | Workflow модулей, где они доступны в приложении |
| Self-update CLI | `fusion update` | Обновления приложения через собственные installers |

Формат проекта на диске тот же (`fusion-framework.toml`, `fusion.<env>.json`, route-модули). Можно сочетать CLI и Desktop на одном проекте.
