## Обновление Fusion Tool

```bash
fusion update
```

Команда проверяет последний [GitHub release](https://github.com/cipherunits/fusion-tool/releases), при наличии более новой версии скачивает сборку для вашей платформы и заменяет работающий бинарник `fusion` на месте через `self-replace`.

### Поддерживаемые цели обновления

| Цель | Примечания |
| --- | --- |
| `x86_64-unknown-linux-gnu` | Linux x86_64 |
| `x86_64-apple-darwin` | macOS Intel |
| `x86_64-pc-windows-msvc` | Windows x64 |

Для других комбинаций OS/arch собирайте из исходников (`cargo install --path .`) или используйте install scripts там, где они поддерживаются. macOS-installer сейчас нацелен на **x86_64** (ARM64 не предлагается как prebuilt в скрипте установки).

### Поведение

- Сохраняет текущее расположение установки — без переустановки и без изменения `PATH`
- Ничего не делает, если вы уже на актуальной версии
- **Не** поднимает pin фреймворка внутри существующих проектов (`fusion-framework.toml` / файлы зависимостей)

Если Fusion Tool установлен в общесистемный каталог, запускайте обновление с правами записи в этот путь:

```bash
sudo fusion update
```
