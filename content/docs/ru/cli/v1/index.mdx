## Overview

Документация CLI описывает инструмент командной строки Fusion для создания, управления и запуска бэкендов из терминала.

Вы просматриваете **v1**. Новые версии появятся в селекторе версий после публикации.

Разработано [Cipher Unit](https://cipherunit.xyz). Графический интерфейс: [Fusion Desktop](/ru/gui).
