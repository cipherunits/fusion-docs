## Обзор

Хелперы заголовков живут в **`fusion-core`** и экспонируются так:

| Язык | Модуль |
| --- | --- |
| Python | `from fusion_framework import header` (или `fusion_framework.header`) |
| TypeScript / Node | `import { header } from "fusion-framework"` |
| C# | Статические хелперы / константы `Header` на `FusionFramework` |

Используйте их при сборке response envelopes:

```python
return self.response(
    body,
    status=status.HTTP_SUCCESS,
    headers=header.download("report.csv", header.TEXT_CSV),
)
```

## Fingerprint-заголовки

Когда fingerprinting включён (`fingerprint.enabled`, по умолчанию `true`), ответы могут включать:

| Constant | Типичное значение |
| --- | --- |
| `X_POWERED_BY` | `Fusion Framework` (`FRAMEWORK_POWERED_BY`) |
| `X_FRAMEWORK` | `Fusion` (`FRAMEWORK_ID`) |
| `X_FUSION_VERSION` | текущая строка версии фреймворка |

## Хелперы-builders

| Helper | Результат |
| --- | --- |
| `attachment(filename)` | `Content-Disposition: attachment; filename=…` |
| `inline(filename?)` | `Content-Disposition: inline…` |
| `content_type(media_type, charset?)` | Карта `Content-Type` |
| `location(url)` | Карта `Location` |
| `cache_control(value)` | Карта `Cache-Control` |
| `download(filename, media_type?)` | attachment + `Content-Type` (по умолчанию `application/octet-stream`) |

Имена файлов приводятся к basename (путь отбрасывается) и экранируются, чтобы избежать header injection.
