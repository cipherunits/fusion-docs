---
title: Чем Fusion не является
description: Границы области — возможности, которых Fusion не предоставляет
---

Fusion — HTTP-фреймворк приложений с общим Rust-ядром. Чтобы не создавать ложных ожиданий: сегодня пакеты фреймворка **не** дают следующих возможностей:

| Не входит | Примечания |
| --- | --- |
| **ORM / слой БД** | Используйте любую DB-библиотеку языка; Fusion свою не поставляет |
| **Контейнер dependency injection** | В Python есть только **parameter binding** запроса; это не IoC |
| **Очереди фоновых задач** | Нет встроенных workers/queues |
| **Runtime маркетплейса плагинов** | Library-пакеты — обычные импорты через CLI |
| **Набор OAuth / session auth** | Только опциональные хелперы middleware Bearer JWT |
| **WebSockets / GraphQL / gRPC** | Модель HTTP request/response |
| **Шаблоны / SSR** | Ориентация на API |
| **Исходники CLI в репозитории** | Scaffolding живёт во внешнем **Fusion Tool** |

Если где-то в документации упоминается возможность, которой нет в языковых гайдах или в этом разделе архитектуры, сверьтесь с исходниками [fusion-framework](https://github.com/cipherunits/fusion-framework), прежде чем на неё полагаться.
