## Маршрут возвращает 404

| Причина | Исправление |
| --- | --- |
| Файл модуля так и не импортирован | Импортируйте его из `main` до `listen()` |
| Тип C# не зарегистрирован | Вызовите `Route.Register<T>()` |
| Неверный путь / нет префикса версии | Проверьте `version=` и раскрытие `[module]` |
| Ошибка в шаблоне custom route | Проверьте шаблон `@http_get` / `@http_post` / … и `[action]` |

## Настройки не загружаются

| Причина | Исправление |
| --- | --- |
| Неверный cwd | Запускайте из корня проекта (`fusion command run:dev`) |
| Неверная среда | Задайте `FUSION_ENV` или используйте `run:prod` / `--prod` |
| Ищете плоские ключи, а файл вложен под `config` | Фреймворк мержит объект `config` — используйте `settings.get("port")`, а не `settings.get("config.port")`, если сами так не сохранили |

## JWT middleware всегда отдаёт 401

- Нет заголовка `Authorization: Bearer …`
- Повреждённый токен при декодировании по умолчанию
- Кастомный `verify` возвращает `None`

## Roles всегда отдаёт 403

- `bearer_jwt` не зарегистрирован до `require_roles` / `roles=`
- В payload нет claim `roles` (или кастомное имя claim не настроено)

## Ошибки native / FFI (C#)

- Соберите `fusion-ffi` или используйте native binary из NuGet-пакета
- Для локальной разработки задайте `FUSION_FFI_PATH`, если загрузчик не находит библиотеку

## Нет Swagger

- `swagger.enabled` равен false
- `swagger.path` отключён
- Приложение упало до mount — смотрите исключения на старте

## Ошибки импорта после fusion add

- Упал build-шаг в `fusion.module.toml`
- Неверное имя пакета `entry`
- Перезапустите `fusion add` и прочитайте вывод CLI

## Порт уже занят

Смените `port` в `fusion.<env>.json` / вложенном `config.port`.
